# Security and confidentiality

These skills are text and two standard-library Python scripts. They make no network calls and store nothing.

The real risk is confidential material. A `matter.json`, a draft or a client document belongs in your own files only. Never paste one into a public issue, pull request or discussion. If you need to show a problem, use an invented example that shows the same thing.

If you find anything in this repository that looks like it comes from a real matter (a name, a case number, a fact), or a script behaving in a way that could expose data, open an issue that describes where it is without quoting it, or use GitHub's private vulnerability reporting for the repository.
